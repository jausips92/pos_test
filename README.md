# 店內點餐 POS

這是依需求建立的店內私人用點餐系統。現在有兩個方向：

- Android 平板自己跑：看 `ipad_pos_app/ANDROID_BUILD_STEPS.md`
- 電腦持續開著、平板連網址：看 `PC_HOSTED_STEPS.md`

## 已完成

- 點餐頁：類別切換、商品 Grid、加入購物車、數量加減、數量為 0 自動移除、總金額、清空確認。
- 列印單：按「列印單」產生熱感紙版型預覽，內容包含單號、品項、數量、單價、列印時間，不含方式、桌號、總結金額。
- 單號規則：`YYMMDD0001`，例如 `2605090001`，每天自動從 `0001` 重新開始。
- 出單機設定頁：IP 輸入、格式檢查、測試連線、儲存到本機。
- 點餐內容設定頁：新增、修改、刪除類別與商品。
- 兩台平板簡單部署：用本資料夾的 `server.js` 當店內區網服務，兩台平板開同一個網址即可共用每日單號序列。

## 執行

```powershell
node server.js
```

啟動後終端機會顯示：

- 本機測試網址：`http://127.0.0.1:4173`
- 區網網址：類似 `http://192.168.x.x:4173`

iPad 與執行伺服器的電腦連同一個 Wi-Fi，Safari 開啟區網網址，再用「加入主畫面」即可當簡單 APP 使用，不需要上架 App Store。

## 出單機備註

目前列印使用瀏覽器列印流程，適合 AirPrint 或系統可見的印表機。若你的熱感出單機是常見 ESC/POS over TCP 9100，下一步可在 `server.js` 加入列印橋接，直接把列印單轉成 ESC/POS 指令送到出單機 IP。

## 單台平板 App

`ipad_pos_app` 是不依賴電腦主機的 Flutter 版本，目前已補 Android 平台：

- 商品、類別、每日單號都存在 iPad 本機 SQLite。
- 單號每天從 `YYMMDD0001` 開始。
- 結帳會產生列印單，並可直接用 TCP 連出單機 IP。
- Android 可打包 APK 安裝到平板。
- iPad 仍需要 Mac + Xcode 或線上打包。
