# yupos Support

yupos is a restaurant POS app for ordering, cart management, menu editing, and network receipt printer setup.

## Basic Troubleshooting

- Confirm the iPad and printer are on the same local network.
- Confirm the printer IP address and port are correct in the printer settings page.
- The default printer port is usually `9100`.
- If menu data does not appear as expected, close and reopen the app, then check the menu management page.

## App Review Notes

The app does not require login. Reviewers can test ordering, cart, menu management, and printer settings without external hardware.
